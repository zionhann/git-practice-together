# 유튜브 클립 모음

깃 · 깃허브 특강 팀 프로젝트용 예제 저장소입니다.

## 이 저장소는 무엇인가요

우리 팀이 각자 추천하는 유튜브 영상을 모아두는 링크 모음 사이트입니다.
`index.html` 한 장짜리 사이트이고, 카드를 누르면 유튜브가 새 탭에서 열립니다.

## 파일 구조

```
.
├── index.html    카드 목록 (팀원 모두가 이 파일 하나를 같이 고칩니다)
└── style.css     공통 스타일 (아무도 고치지 않습니다)
```

## 영상 ID 찾기

유튜브 주소에서 `v=` 뒤에 오는 11 글자가 영상 ID 입니다.

```
https://www.youtube.com/watch?v=dQw4w9WgXcQ
                                ~~~~~~~~~~~  ← 이 부분
```

카드 블록 안에 이 ID 가 두 번 들어갑니다. 링크와 썸네일 주소입니다.

- 링크 `https://www.youtube.com/watch?v=<영상ID>`
- 썸네일 `https://img.youtube.com/vi/<영상ID>/hqdefault.jpg`

## 내 클립을 추가하는 방법

1. **이슈를 만듭니다** — `Issues` 탭 → `🎬 클립 추가` 템플릿을 채웁니다.
   만들어진 이슈의 번호(`#12` 같은)를 확인해 둡니다
2. **브랜치를 만듭니다** — 이름은 `feat/#{이슈번호}` 입니다

   ```bash
   git switch main
   git pull
   git switch -c 'feat/#12'   # 따옴표를 빼먹으면 안 됩니다
   ```

   `#` 는 터미널에서 주석 기호라서, 작은따옴표로 감싸지 않으면 브랜치 이름이 잘립니다

3. **카드를 붙입니다** — `index.html` 의 카드 블록
   (`▼▼▼ 카드 하나 시작` ~ `▲▲▲ 카드 하나 끝`)을 복사해 목록 아래에 붙이고,
   영상 ID 두 군데를 바꾼 뒤 제목·채널·소개·추천인을 내 것으로 채웁니다
4. **커밋합니다** — 메시지는 `타입: 설명` 형식입니다

   ```bash
   git add index.html
   git commit -m "feat: Never Gonna Give You Up 클립 추가"
   ```

   클립 추가는 `feat`, 오타나 깨진 링크 수정은 `fix` 입니다.
   자세한 규칙은 [CLAUDE.md 의 커밋 컨벤션](CLAUDE.md#커밋-컨벤션) 을 보세요

5. **푸시하고 PR 을 만듭니다** — 대상 브랜치는 `main` 입니다

   ```bash
   git push -u origin 'feat/#12'
   ```

   PR 본문의 `Closes #` 뒤에 **이슈 번호를 적습니다.**
   그래야 머지될 때 이슈가 자동으로 닫힙니다

## 충돌이 났을 때

팀원 모두가 `index.html` 의 같은 자리를 고칩니다. **충돌이 나는 것이 정상입니다.**

**먼저 머지된 쪽이 우선입니다. 뒤에 오는 사람이 직접 해결합니다.**
내 PR 에 충돌이 뜨면 `main` 이 아니라 **내 브랜치에서** 해결합니다.

```bash
git switch 'feat/#12'
git fetch origin
git merge origin/main     # 여기서 충돌이 납니다

# index.html 을 열어 아래처럼 정리한 뒤
git add index.html
git commit
git push
```

`index.html` 을 열면 이런 표시가 보입니다:

```html
<<<<<<< HEAD
  ... 내 카드 ...
=======
  ... 먼저 머지된 카드 ...
>>>>>>> origin/main
```

- **어느 쪽도 지우지 않습니다.** 두 카드가 모두 남아야 합니다
- `main` 쪽 카드를 위에, 내 카드를 아래에 두고
  `<<<<<<<`, `=======`, `>>>>>>>` 세 줄만 지웁니다
- 정리한 뒤 `index.html` 을 브라우저로 열어 카드가 모두 보이는지 확인합니다

## 주의

- 이미 머지된 다른 사람의 카드는 지우거나 자리를 옮기지 않습니다
- `style.css` 는 아무도 고치지 않습니다
- HTML 을 실제로 구현하는 과제가 아닙니다. 카드를 붙이고 링크를 연결하는 것까지가 범위입니다
